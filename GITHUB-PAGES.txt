ネコビーム RUSH — GitHub Pagesでの公開

1. ZIPを解凍します。
2. GitHubリポジトリの一番上に、index.html・style.css・game.jsを一緒にアップロードします。
   ZIPそのものではなく、解凍したファイルをアップロードしてください。
   既存ゲームがある場合は、新しいリポジトリを使ってください。
3. リポジトリの Settings → Pages を開きます。
4. Sourceで Deploy from a branch を選び、main / (root) を指定してSaveします。
5. 公開後、Pagesに表示されるHTTPSのURLをスマートフォンで開きます。

スマートフォン操作
・「出撃する」で開始。
・画面を指でドラッグして左右へ移動。攻撃は自動です。
・強化ゲートは、通過時にいる側を選択します。
・横向きでの確認がおすすめです。縦向き表示にも対応しています。

README.mdはゲーム仕様の説明です。GITHUB-PAGES.txtとREADME.mdは公開に必須ではありません。
通信ライブラリ・画像素材・ビルド作業は不要です。
