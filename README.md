# ネコビーム RUSH

`index.html` をダブルクリックしてブラウザで開いてください。インストール・ビルド・外部素材・通信は不要です。

## 操作
- 「出撃する」で開始。攻撃は自動です。
- ← → または A / D で左右移動。画面をドラッグしても移動できます。
- 強化ゲート到達時に、軍団の中心がある側の強化を取得します。中央ちょうどでは左を選びます。
- 道幅を約16%狭くしました。戦闘中は左右交互のサイドから強化アイテムが流れてきます。手前に来たときに近づくと取得できます。内容はネコ+1・攻撃力+1・連射+1。取り逃してもペナルティはありません。通常アイテムは戦闘開始4.8秒後、迫っている敵の側から出現します。中ボスの最初の攻撃予告では、予告範囲へ攻撃力+1アイテムが流れます（1波につき1回）。攻撃を避けてから戻って拾うこともできます。
- P または右上のボタンで一時停止。別ウィンドウへ移動すると自動停止します。
- SOUND ボタンで効果音の有効・無効を切り替えます。
- クリア・ゲームオーバー後の RETRY で最初から遊べます。

## 試作版のルール
全5波と4回の二択ゲート。敵を大量に追加する構成から、通常敵・装甲敵・中ボスの混成に変更しました。

| 波 | 通常 | 青よろい | 赤よろい | 中ボス |
|---|---:|---:|---:|---:|
| 1 | 55 | 0 | 0 | 0 |
| 2 | 38 | 8 | 0 | 0 |
| 3 | 40 | 8 | 0 | 1 |
| 4 | 44 | 6 | 8 | 2 |
| 最終 | 50 | 8 | 12 | 2＋巨大ロボ |

青よろいはHP8、赤よろいはHP18。通常敵より大きく、鎧とHPバーで見分けられます。紫の中ボス「ネズミ隊長」は王冠付きで、HPは第3波360、第4波500、最終波640。第4波以降は左右に1体ずつ登場します。隊長は中距離（奥行き0.65）から攻撃周期を開始し、手前では止まります。通常時は盾でダメージを75%軽減します。約1秒の赤い予告表示の後に、予告開始時のプレイヤー位置へ攻撃します。横移動で回避できます。予告中は体を縮めてため、攻撃時は踏み込みと衝撃波、攻撃後はよろける動作を表示します。これらの動作は見た目のみで、攻撃タイミングや当たり判定は変わりません。攻撃後は2.4秒間の隙ができ、盾が消え、HPバーが金色に変わり、受けるダメージが通常攻撃力の2.5倍になります（装甲中の10倍）。倒すまで次のゲートは出現しません。

通常敵の突破は1ダメージ、装甲敵は2ダメージ。累積3ダメージでネコ1匹を失い、0匹で終了します。敵の説明文・名前・HP数値は表示せず、残りHPはバーで示します。攻撃予告は赤い範囲表示だけです。巨大ロボのHPは最低1800、人数に応じて増えます。通常時は70%ダメージ軽減。遠距離から約1秒の予告後に2ダメージの攻撃を放ち、横移動で回避できます。攻撃後2秒は装甲が開き、ダメージが1.5倍になります。HP半分以下では攻撃周期が3秒から2.3秒へ短縮します（別途2秒の隙があります）。最終波の出現が終わり、残っている敵と巨大ロボを倒すとクリアです（突破された敵は撃退数に加算されません）。

第1波は0.08秒間隔、第2波以降は0.22〜0.24秒間隔で最大2〜3匹ずつ出現します。初期射撃間隔は0.28秒（約3.6発/秒）です。ビームは近い敵を自動照準しますが、横方向に射程があるので左右へ動いて敵を捉えてください。ネコ1匹ごとに射撃し、最大30匹を隊列表示・射撃処理します（人数上限60）。ビーム強化は1レベルごとに攻撃力+2と連射補正を得ます。Lv2で2WAY、Lv3以降で3WAY、Lv5で太いビーム。ゲートの連射強化は連射レベル+2、サイドアイテムは+1です。

## ファイル
- index.html：画面とHUD
- style.css：レイアウト、横画面と縦画面の対応
- game.js：入力・戦闘・ステージ・図形描画

`game.js` の `cat` / `mouse` / `robot` が画像への差し替え箇所です。`enemyTypes` は敵の性能と配色、`encounters` は各波の編成です。`upgrades` が強化の定義、`gatePairs` が出現順です。リスク付き強化は `apply` に複数のステータス変更を追加できます。

## スマホ表示・操作の修正
スマホは縦画面を基本とし、表示領域いっぱいに描画します。道・敵・隊列・ゲートは縦画面用の座標で配置し、キャラクターを縦に引き伸ばしません。下部をスライドして操作できます。横向きでは16:9表示へ切り替わります。指を置いただけでは移動せず、滑らせた量で左右移動します。指を離す・入力キャンセル・回転・一時停止時にドラッグを解除します。実機での再確認は別途必要です。


画面上のWAVE表記は表示しません。

## 戦闘テンポ
波間の強化ゲートは約2.3秒で到達します。選択中から次の波の先頭6匹が進入し、自動射撃が続きます。この6匹は次の波の編成に含まれ、敵の総数は増えません。
